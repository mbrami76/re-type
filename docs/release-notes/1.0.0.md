# Re:Type 1.0.0

First public release. Re:Type types the text on the Windows clipboard into the field you are working in, as simulated keystrokes. It is an assistive tool for places where pasting is blocked or unreliable: remote consoles, virtual machines, password fields, installers and legacy applications.

## What it does

- Types the clipboard text with a global hotkey (default `Ctrl+Alt+Shift+V`), or with the tray command **Type clipboard now**. Press `Esc` to stop.
- **Pick target and type**: click the exact field that should receive the text.
- Safe by default: line breaks and tabs are skipped, special characters become plain ASCII punctuation, the clipboard is emptied after a successful run, and text over a limit is refused.
- Private: no network access, no copy of the text is kept, and the log never contains typed text.
- Templates: text and a few navigation keys before or after the clipboard text, each with its own hotkey.
- Shortcut fields that check what you type, show key names in your language and put modifiers in a fixed order.
- Start at sign-in, optional run as administrator (also from the tray menu, for one run), dark mode, high contrast, keyboard and screen-reader use, formatted in-app Help.
- Interface in English, Italian, French, German, Spanish and Portuguese. Only English and Italian were checked by native speakers; corrections are welcome.
- One portable executable, no installer. Put a file named `portable` next to it to keep settings and log in the same folder.

## Download and check

Download `re-type-1.0.0.exe` below. Windows 10 and 11, 64-bit. To check the download, compare its SHA-256 with the `.sha256` file (`Get-FileHash re-type-1.0.0.exe` in PowerShell).

## Known limits

- The executable is **not code-signed yet**, so Windows SmartScreen may warn about an unknown publisher.
- Tested on Windows 10 and Windows 11 virtual machines. Not tested: display scales above 100 %, JAWS and Narrator (NVDA was tried), and a signed build.
- The Windows-specific code has no automated tests; see `docs/testing.md`.
- Programs that read raw scan codes may ignore the typed characters, and Windows does not allow typing into an elevated window unless Re:Type runs as administrator too. See the user guide for the full list.
